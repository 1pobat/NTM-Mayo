Игровые регистрации, native рецепты и серверные/клиентские привязки написаны.
**Мод не объявляется готовым. Полная компиляция и запуск ещё не выполнены.**

## Фактические проверки

- Оригинальный NTM восстановлен из трёх частей без изменения байтов. Все ZIP CRC
  исправны. 6441 класс; Implementation-Version `1.0.3+1b8c6c2d`.
- Классы и дескрипторы NTM изучены напрямую, без пересборки/модификации его JAR.
- JDK 25.0.5 и Gradle Wrapper 9.2.1 установлены. Инфраструктурное препятствие
  «нет Java/Gradle» устранено; больше просить их у пользователя не требуется.
- `tools/check_core.py` проходит на Java 21 и Java 25: 1792 assertions.
  Число уменьшено относительно раннего прототипа: из test fixtures убраны
  три ненужных fallback-рецепта; оставлены восемь реальных машинных рецептов.
- `tools/check_resources.py`: 17 машинных/верстачных рецептов, 58 JSON, 44 PNG;
  проверены локализация, CRC изображений, реальные ресурсные ссылки NTM,
  отсутствие батарей в двух модулях и сохранение состояния в loot components.
- Разобран синтаксис 29 Java-файлов основного кода. Это не проверка типов/API.
- Звук — оригинальный Vorbis mono 44100 Hz.

## Последний результат Gradle

Выполнен реальный запуск Wrapper на JDK 25:

```
./gradlew --no-daemon build
> Task :createMinecraftArtifacts FAILED
Could not resolve net.neoforged:neoform-runtime:2.0.31
https://maven.neoforged.net/releases/... -> HTTP 403 Forbidden
```

Запуск с `--offline` подтвердил отсутствие этой зависимости в кэше.
Компилятор ещё не дошёл до проверки игровых исходников. Ошибки типов и runtime
интеграции могут оставаться; их нужно исправить после разрешения зависимостей.
Проблема доверия сертификату нового JDK исправлена через системное CA-хранилище,
TLS не отключался. Дальнейшие одинаковые скачивания при 403 не выполняются.

Пользователь сообщил о добавлении доменов в настройки среды, однако последнее
наблюдение текущего экземпляра всё ещё не содержит их в активном списке.
Нужна конфигурация, применённая именно к запущенной среде:

- maven.neoforged.net
- libraries.minecraft.net
- piston-meta.mojang.com
- piston-data.mojang.com
- resources.download.minecraft.net

Для dev-запуска клиента с Crankshaft также потребуется repo.warfactory.co.
