# Проверка перед выпуском

Все игровые сценарии ниже **ожидают выполнения** после успешной полной сборки.
Проверки чистого ядра и JSON не подтверждают поведение Minecraft/NeoForge.
Среда проверки: Java 25, Minecraft 26.2, NeoForge 26.2.0.89, оригинальный NTM NEXT
1.0.3+1b8c6c2d; для клиента также обязательная зависимость NTM Crankshaft.

| № | Сценарий и ожидаемый результат | Доступная предварительная проверка |
|---|---|---|
| 1 | Запустить dedicated server и клиент с отдельным JAR аддона; проверить отсутствие registry, codec и mixin ошибок. | Синтаксис Java, аудит оригинального JAR; запуск не выполнен. |
| 2 | Найти все предметы и жидкости, переключить RU/EN, проверить текстуры, вкладку и названия. | JSON, PNG CRC, равенство ключей локализации. |
| 3 | Выполнить восемь машинных рецептов; проверить количества, время, тару и отсутствие дублирования при заполненном выходе. Mixer использует native расход энергии. | Рецепты, реальные ID предметов NTM, тестовые расчёты. |
| 4 | Скрафтить модули по согласованным шаблонам без батарей, проверить взаимоисключение в одном нагрудном слоте. | Шаблоны JSON и native API; игровой слот не проверен. |
| 5 | Подать промышленный майонез в газовую турбину; сравнить расход со штатной смазкой: 85%; проверить штатную смазку после опорожнения. | Чистая функция коэффициента; native передача не проверена. |
| 6 | Перегреть майонезную смазку выше настройки: свойства пропадают, жидкость становится отработанной, производство прекращается. | Расчёты ядра; native температура и поток ожидают проверки. |
| 7 | Включить адаптер RBMK: эффективность охлаждения 60% штатной, активная работа 600 тиков, затем отработанная жидкость и SCRAM, без взрыва. | Счётчик ядра; реальный реактор не запущен. |
| 8 | Сохранить мир, выгрузить чанк, долить/слить свежую жидкость, перенести адаптер: срок службы не сбрасывается; полный слив отработанной разрешает новый цикл. | Сериализация и перенос состояния, заполнение/слив. |
| 9 | Выпить Flashgold: бесконечное состояние, DT +3 HP, исходящий урон +30%, скорость +20%, лечение 1 HP каждые 100 тиков. | Расчёты и жизненный цикл ядра; native модификаторы ожидают проверки. |
| 10 | Повторная банка не расходуется и не обновляет состояние; после смерти бонусы исчезают; перелогин и смена измерения не дублируют бонусы. | Ядро активации/очистки/сериализации. |
| 11 | Проверить нестабильность на обычном HP после DT/DR/брони, с дополнительным Shield и без него; малый урон до 0.5 сердца не повышает шкалу. | Формула и учёт фактической потери HP, включая вложенный урон и лечение внутри события. |
| 12 | Без потери HP шкала сама не растёт и не падает; на 99% штрафов нет. | Ядро таймеров и границ. |
| 13 | При 100% наступает немедленная смерть сквозь защиту и тотем; локальные золотые частицы, отдельный звук и сообщение, без урона блокам/соседям. | Порог ядра и ресурсы; обход native возрождения не проверен в игре. |
| 14 | Пассивный модуль: после 160 тиков без потери HP снижает на 0.5 процентного пункта в секунду, расходуя HE; без энергии не работает. | Таймер, энергия и нижняя граница ядра. |
| 15 | Entropy Reclaimer: убийства разных живых существ в ближнем бою и снарядом снижают ровно на 7 процентных пунктов, минимум ноль; одна жертва засчитывается один раз, cooldown отсутствует, требуется HE. | Ядро абсолютного вычитания, энергии и дедупликации; native атрибуция ожидает проверки. |
| 16 | Инъектор снижает на 25 пунктов, cooldown 1200 тиков сохраняется; при неуспехе предмет не тратится. | Ядро состояния, таймера и сохранения. |
| 17 | Камера в радиусе 3 снижает на 1 пункт/сек с HE; снаружи не действует, игрок не обрабатывается дважды за такт. Проверить питание native сетью и батареей. | Радиус, дедупликация и энергия ядра; native сеть не проверена. |
| 18 | HUD виден только владельцу с активной инфузией, показывает процент и предупреждение от 75%, следует настройкам координат; проверить два клиента и dedicated server без клиентских классов. | Валидация snapshot и ресурсов; рендеринг/сеть не проверены. |

Результаты игровых запусков записывать отдельно с версией JAR, логами и фактическим
наблюдением. До их выполнения и успешного Gradle build статус остаётся «не готов».
